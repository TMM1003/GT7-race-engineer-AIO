# TrackDB Attribution

The files in this directory are a curated subset of:

- Repository: TUMFTM/racetrack-database
- URL: https://github.com/TUMFTM/racetrack-database
- License: GNU Lesser General Public License v3.0
- Local license copy: `trackdb/LICENSE`

The upstream dataset provides centerlines, track widths, and optimized
minimum-curvature racelines for real-world circuits. This project retains only
the entries that correspond to GT7-supported real-world locations and uses them
as external geometry baselines after alignment into GT7 telemetry coordinates.

The original data sources and processing notes are documented in
`trackdb/README.md`.
